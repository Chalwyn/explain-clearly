# 一眼看懂 · explain-clearly

让 AI 先说答案，用合适的形式解释清楚，并保留影响结论的条件。

适合读专业文档、理解概念、比较选项、梳理流程，以及观察参数变化。它降低阅读负担，不强制把所有回答缩成几句话，也不会自动改写一般创作、翻译或开发任务。

## 它怎样选择输出形式

优先使用能讲清问题、阅读负担最小的形式。用户指定的形式和深度优先。

| 你想弄懂什么 | 通常怎样回答 |
| --- | --- |
| 一个概念或原因 | 先给结论，再补必要解释 |
| 几个选项的区别 | 按相同维度做一张对比表 |
| 一件事怎么做 | 编号步骤或箭头流程 |
| 结构、因果或变化 | 简图或图表，配短说明 |
| 调参数会发生什么 | 交互图或单页 HTML 工具 |
| 明确要求视频讲解 | 根据当前工具能力制作视频或提供替代产物 |

默认只选一种主要形式。文字使用短句、常用词和统一术语；不堆小标题，不反复总结。简化时保留前提、例外、概率、单位和期限。

## 安装到 Codex

1. 下载本目录，保留其中的文件结构。
2. 在你的用户目录下打开或新建 `.codex/skills/`。
3. 把整个 `explain-clearly` 文件夹复制进去。
4. 重新打开 Codex 会话，输入 `$explain-clearly` 调用。

安装后，主文件应位于 `~/.codex/skills/explain-clearly/SKILL.md`。其中 `~` 表示你的用户目录；Windows 对应 `%USERPROFILE%`。避免多套一层同名文件夹。若已有同名技能，先备份再替换。

```text
explain-clearly/
├── README.md          # 安装方法和使用示例
├── SKILL.md           # AI 实际执行的解释规则
└── agents/
    └── openai.yaml    # Codex 中显示技能的名称和提示信息
```

## 三种调用示例

**短文：理解一个概念**

```text
$explain-clearly 什么是通货膨胀？
先用一句话回答，再解释它怎样影响同样一笔钱的购买力。
不要用比喻。
```

**对比：看懂两种选择**

```text
$explain-clearly 等额本息和等额本金有什么区别？
用一张表比较每月还款、前期压力和总利息。
把比较成立的条件写在表格附近。
```

**交互：调整参数，观察结果**

```text
$explain-clearly 做一个单页 HTML，比较等额本息和等额本金。
让我输入贷款金额、年限和固定年利率。
用两条曲线显示逐月还款，并显示各自的总利息。
说明计算假设，处理零利率和无效输入，提供可直接打开的文件。
```

## 其他 AI 怎么用

如果当前系统不支持技能安装，打开 [SKILL.md](SKILL.md)，复制开头 YAML 信息块之后的 Markdown 正文，放进自定义指令，或粘贴到问题前面。无需复制这份 README 或 `agents/openai.yaml`。

## 能力边界

- 中文写作规则借鉴 ASD-STE100 的受控语言思路，不代表符合该标准，也不是认证标准的替代品。“每句约 30 字”只是可读性参考。
- 图表渲染、网页文件、交互预览和视频生成取决于当前 AI 平台的工具能力。技能本身不附带浏览器、视频渲染器或配音服务。
- 表达更清楚不会自动提高事实准确性。关键结论仍需对应原始依据；计算工具需要核对公式与算例。
- 阅读体检报告、保险条款或合同时，应保留原文的适用条件。异常指标不能直接当作诊断，局部条款也不能证明一定理赔。
